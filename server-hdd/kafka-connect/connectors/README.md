# Connector templates

`debezium-sqlserver.json` recibe endpoints mediante variables de entorno de Kafka Connect. Su `table.include.list` usa expresiones regulares con puntos escapados para capturar exactamente las tres tablas de la base fija `my_db_transaction`. `scylladb-sink.json.template` se renderiza localmente con los nombres de topicos y keyspace del `.env` de este componente; mapea los tres topicos CDC a `si_fin_kardex`, `si_fin_agencia_cce` y `si_fin_canal_cce`. Como las columnas CQL no estan entre comillas, el lado izquierdo de cada mapping usa sus nombres en minusculas. Las tablas SQL Server ya existen y este repositorio nunca las crea.
